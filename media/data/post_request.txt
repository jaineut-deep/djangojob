В прошлых статьях мы рассмотрели, как отправлять клиенту некоторые данные, в том числе файлы.
Но веб-серверы не только отдают данные, но и принимают их (например, формы логина) через POST-запросы.
Для этого в обработчике BaseHTTPRequestHandler используется метод do_POST, который вызывается,
если сервер получил POST-запрос.

Самая сложная часть здесь - прочитать данные. Они не передаются в аргументах,
их нужно читать из потока self.rfile (потока входных данных), ориентируясь на длину контента.

Для упрощения отправки данных определим html-файл login.html с формой для ввода данных:

```
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>METANIT.COM</title>
</head>
<body>
    <h1>Login Page</h1>
    <form method="POST">
    <p>
        <label>Login</label><br>
        <input name="login" />
    </p>
    <p>
        <label>Password</label><br>
        <input name="password" type="password" />
    </p>
    <input type="submit" value="Send">
    </form>
</body>
</html>
```

Это условная форма с двумя полями для ввода логина и пароля.
